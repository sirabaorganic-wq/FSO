---

### Key Matrix Invariants
1. **Zero Client Authority**: The frontend never determines payment amount, currency, or payment status.
2. **Provider Confirmation**: Signature verification is paired with `fetchPaymentDetails` or webhook delivery to ensure provider capture status.
3. **Rebinding Guard**: Exactly one `Payment` record per `razorpayPaymentId`; payment ID cannot be stolen by or rebound to another order.
4. **Frozen Schema Compliance**: Native Prisma queries and transactional mutations without altering `schema.prisma`.
