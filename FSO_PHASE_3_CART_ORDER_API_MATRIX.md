# FSO Phase 3: Cart & Order API Matrix

| Endpoint | Method | Auth | Request | Prisma Models | Ownership | Validation | Response | Error Contract | Frontend Status |
|---|---|---|---|---|---|---|---|---|---|
| `/api/cart` | `GET` | `Bearer JWT` | None | `Cart`, `CartItem`, `Product` | Scoped strictly to `req.user.id` | Valid JWT required | `200 OK`: Array of enriched `CartItem` objects with current product pricing, stock, metadata | `401 UNAUTHENTICATED`, `500 INTERNAL_ERROR` | `LIVE` |
| `/api/cart` / `/api/cart/add` | `POST` | `Bearer JWT` | `{ productId: string, quantity?: number, variant?: string }` | `Cart`, `CartItem`, `Product`, `User` | Scoped strictly to `req.user.id` | `productId` non-empty (resolved via CUID or slug); quantity integer $1 \le q \le 100$; product exists, is active, public, and stock $> 0$ | `200 OK`: Array of enriched `CartItem` objects | `400 OUT_OF_STOCK`, `401 UNAUTHENTICATED`, `404 NOT_FOUND`, `422 VALIDATION_ERROR`, `500 INTERNAL_ERROR` | `LIVE` |
| `/api/cart` | `PUT` | `Bearer JWT` | `{ cartItems: Array<{ productId: string, quantity: number, variant?: string }> }` | `Cart`, `CartItem`, `Product`, `User` | Scoped strictly to `req.user.id` | `cartItems` is array; each item has valid product reference and integer $1 \le q \le 100$ | `200 OK`: Array of updated enriched `CartItem` objects | `401 UNAUTHENTICATED`, `422 VALIDATION_ERROR`, `500 INTERNAL_ERROR` | `LIVE` |
| `/api/cart/item/:id` | `PUT` | `Bearer JWT` | `{ quantity: number }` | `Cart`, `CartItem`, `Product`, `User` | Scoped strictly to item in `req.user.id`'s cart | Quantity integer $1 \le q \le 100$; item must belong to user's cart | `200 OK`: Array of updated enriched `CartItem` objects | `401 UNAUTHENTICATED`, `404 NOT_FOUND`, `422 VALIDATION_ERROR`, `500 INTERNAL_ERROR` | `LIVE` |
| `/api/cart/item/:id` | `DELETE` | `Bearer JWT` | None | `Cart`, `CartItem`, `Product`, `User` | Scoped strictly to item in `req.user.id`'s cart | Target ID resolves to item in user's cart | `200 OK`: Array of updated enriched `CartItem` objects | `401 UNAUTHENTICATED`, `404 NOT_FOUND`, `500 INTERNAL_ERROR` | `LIVE` |
| `/api/cart` | `DELETE` | `Bearer JWT` | None | `Cart`, `CartItem`, `User` | Scoped strictly to `req.user.id` | Valid JWT required | `200 OK`: `[]` | `401 UNAUTHENTICATED`, `500 INTERNAL_ERROR` | `LIVE` |
| `/api/orders` | `POST` | `Bearer JWT` | `{ orderItems: Array<{ productId: string, quantity: number, variant?: string }>, shippingAddress: object, paymentMethod: string, couponCode?: string, gstClaimed?: boolean, buyerGstNumber?: string, businessName?: string }` | `Product`, `Coupon`, `Order`, `OrderItem`, `VendorOrder`, `Cart`, `CartItem`, `User` | Scoped strictly to `req.user.id`; vendor derived strictly from `Product.vendorId` | `orderItems` non-empty array; each item valid integer quantity $1 \le q \le 100$ and resolvable product reference (CUID or slug); stock verified with concurrency-safe decrement; coupon verified against DB (client `discountAmount` discarded) | `201 Created`: Authoritative Order DTO with line items and vendor orders | `400 EMPTY_CART` / `PRODUCT_UNAVAILABLE` / `INSUFFICIENT_STOCK` / `INVALID_COUPON` / `EXPIRED_COUPON` / `COUPON_LIMIT_REACHED` / `COUPON_MIN_ORDER`, `401 UNAUTHENTICATED`, `422 VALIDATION_ERROR`, `500 INTERNAL_ERROR` | `LIVE` |
| `/api/orders/myorders` | `GET` | `Bearer JWT` | None | `Order`, `OrderItem`, `VendorOrder` | Scoped strictly to `userId: req.user.id` | Valid JWT required | `200 OK`: Array of user orders | `401 UNAUTHENTICATED`, `500 INTERNAL_ERROR` | `LIVE` |
| `/api/orders/:id` | `GET` | `Bearer JWT` | None | `Order`, `OrderItem`, `VendorOrder`, `Vendor` | Owner (`order.userId === req.user.id`) or Admin | Target ID resolves to existing order | `200 OK`: Order detail DTO | `401 UNAUTHENTICATED`, `403 FORBIDDEN`, `404 NOT_FOUND`, `500 INTERNAL_ERROR` | `LIVE` |
| `/api/orders/:id/cancel` | `POST` | `Bearer JWT` | `{ reason?: string }` | `Order`, `OrderItem`, `VendorOrder`, `Product` | Owner (`order.userId === req.user.id`) or Admin | Order exists, owned by user, status not `SHIPPED`, `DELIVERED`, or `CANCELLED` | `200 OK`: `{ success: true, message: string, order: object }` (stock restored, status set to `CANCELLED`) | `400 INVALID_ORDER_STATE`, `401 UNAUTHENTICATED`, `403 FORBIDDEN`, `404 NOT_FOUND`, `500 INTERNAL_ERROR` | `LIVE` |
| `/api/orders/track/:id` | `GET` | Public | None | `Order`, `OrderItem` | Public tracking by `id` or `orderNumber` | Valid order number or ID format | `200 OK`: Order tracking DTO with status and line items | `404 NOT_FOUND` | `LIVE` |
| `/api/orders` | `GET` | `Bearer JWT (Admin)` | None | `Order`, `User`, `OrderItem`, `VendorOrder`, `Vendor` | Admin only (`req.user.isAdmin`) | Admin privileges verified | `200 OK`: All platform orders | `401 UNAUTHENTICATED`, `403 FORBIDDEN`, `500 INTERNAL_ERROR` | `LIVE` |
| `/api/orders/analytics` | `GET` | `Bearer JWT (Admin)` | None | `Order`, `User` | Admin only (`req.user.isAdmin`) | Admin privileges verified | `200 OK`: Platform commerce metrics | `401 UNAUTHENTICATED`, `403 FORBIDDEN`, `500 INTERNAL_ERROR` | `LIVE` |
| `/api/orders/:id/status` | `PUT` | `Bearer JWT (Admin)` | `{ status: string }` | `Order`, `VendorOrder` | Admin only (`req.user.isAdmin`) | Valid order status enum | `200 OK`: Updated order DTO | `401 UNAUTHENTICATED`, `403 FORBIDDEN`, `404 NOT_FOUND`, `500 INTERNAL_ERROR` | `LIVE` |
| `/api/orders/:id/admin/refund` | `POST` | `Bearer JWT (Admin)` | `{ reason?: string }` | `Order`, `RefundLog` | Admin only (`req.user.isAdmin`) | Order exists | `200 OK`: Refund status and log | `401 UNAUTHENTICATED`, `403 FORBIDDEN`, `404 NOT_FOUND`, `500 INTERNAL_ERROR` | `LIVE` |
